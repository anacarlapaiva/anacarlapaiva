Como eu trabalho
Arquitetura por features. Cada funcionalidade reúne seus componentes, hooks e serviços no mesmo lugar, para o projeto crescer sem virar um emaranhado.
Especificação antes do código. Uso Spec-Driven Development: a spec vem primeiro e a implementação segue a partir dela, inclusive quando trabalho com agentes de IA.
Contexto de IA versionado e agnóstico. AGENTS.md, regras e skills no repositório, funcionando com qualquer modelo ou ferramenta.
Interface em primeiro lugar. Acessibilidade e experiência de uso entram no projeto desde o começo, não no fim.
